# ppautohaus-site

Redesign of ppautohaus.com.au (Peters Prestige Autohaus), built with Astro as a static site.

- `npm install`, then `npm run dev` or `npm run build` (output goes to `dist/`)
- Cloudflare Pages: build command `npm run build`, output directory `dist`, no adapter needed.
- Not deployed, and DNS has not been touched.
